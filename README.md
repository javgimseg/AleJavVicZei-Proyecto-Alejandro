PROYECTO INTERMODULAR 2º DAM
## Reto 1
Construcción del equipo y preparación del proyecto
Objetivo de la tarea
Preparar el equipo de proyecto definiendo roles, normas de funcionamiento, mecanismos
de comunicación, gestión de conflictos y entorno de trabajo en GitHub.
Actividad a realizar
## 1. Los proyectos fracasan cuando...
Analizad y debatid sobre experiencias previas de trabajo en grupo e identificad problemas
habituales. Os dejo una lista de posibles problemas:

- Falta de comunicación o malentendidos
- Reparto desigual de tareas
- Incumplimiento de plazos
- Desacuerdos en decisiones
- Desmotivación
- Conflictos personales
- Falta de organización
- Ausencias o retrasos repetidos
- Calidad insuficiente
- Dependencia de una única persona
- No documentar adecuadamente
- Mal uso de GitHub

Completad una tabla con al menos 8 problemas, sus consecuencias y posibles soluciones.
## 2. Definición de roles Scrum
Investigad los siguientes roles:

- Product Owner
- Scrum Master
- Equipo de Desarrollo
  
Para cada rol indicad responsabilidades, habilidades necesarias, ventajas y dificultades.
Reflexión individual: ¿qué rol me gustaría desempeñar y por qué?

## 3. Contrato de trabajo del equipo

Elaborad un contrato de equipo que incluya los siguientes apartados:

### 1. Datos generales
   
- Nombre del equipo y del proyecto.
- Miembros del grupo y roles (Scrum Master, Product Owner, Desarrolladores, etc.).
- Fecha de inicio y duración del proyecto.

### 2. Objetivos del equipo
   
- Qué pretende lograr el grupo (resultado final o producto).
- Objetivos actitudinales: colaboración, respeto, puntualidad, mejora continua.
### 3. Normas de funcionamiento
  
- Horarios de trabajo, horario de reunión semanal sprint review.
- Uso de herramientas (Trello, Office 365, Github...).
- Canales oficiales de comunicación.

### 4. Toma de decisiones

- Cómo se toman las decisiones (por consenso, votación, validación del Scrum Master…).

### 5. Resolución de problemas

- Cómo actuar si hay incumplimientos o desacuerdos. Tratar todos los problemas
debatidos en clase

### 6. Compromiso individual

- Cada miembro asume el compromiso de colaboración, respeto, puntualidad,
comunicación de dificultades con antelación
• Aceptación de que la nota grupal puede verse afectada por la implicación individual.
## 4. Preparación del entorno GitHub
- Crear la organización
- Crear repositorio del proyecto
- Crear README inicial. Debe incluir
- Nombre del proyecto
- Descripción
- Integrantes
- Tecnologías previstas
- Estado actual
- Enlace al tablero del proyecto (si existe)
- Crear rama personal
- Realizar commit y push individual
### Entrega

- Documento grupal con análisis de problemas
- Ficha individual de roles Scrum
- Contrato de equipo firmado
- Repositorio GitHub creado con primer commit de cada integrante
  
### Evaluación
Se valorará la participación activa, la calidad de las reflexiones, la coherencia del contrato de
equipo, la correcta asignación de roles y la puesta en marcha del repositorio GitHub.
